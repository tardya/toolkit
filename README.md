# Toolkit

Консольное приложение на Python, объединяющее точный математический калькулятор и конвертер единиц измерения. Проект реализован в рамках лабораторной работы.

## Назначение проекта

Проект предоставляет интерфейс командной строки (CLI) для решения двух задач:
- Вычисление сложных арифметических выражений с высокой точностью (поддержка скобок, приоритетов операций, целочисленного деления и остатка).
- Конвертация физических величин (длина, масса, температура) на основе заданных коэффициентов.

Для работы с приложением используется запуск модуля напрямую:
`python -m src.toolkit`

Просмотр базовой справки по командам:
`python -m src.toolkit --help`

## Установка и запуск

Для работы требуется установленный интерпретатор Python 3.

Рекомендуется запускать проект в изолированном виртуальном окружении:
1. Создание виртуального окружения:
   `python -m venv venv`
2. Активация окружения:
   - Для Windows: `venv\Scripts\activate`
   - Для Linux/Mac: `source venv/bin/activate`
3. Установка зависимостей (если требуется для линтера и тестов):
   `pip install pytest ruff`

Для выхода из виртуального окружения введите:
`deactivate`

## Структура проекта

Весь исходный код изолирован в пакете `src.toolkit`.

- `__main__.py` — CLI-парсер (на базе `argparse`), обработка подкоманд и точка входа.
- `calculator.py` — модуль лексического анализа (токенизатор), синтаксического анализа (перевод в обратную польскую запись — RPN) и вычисления.
- `errors.py` — иерархия пользовательских исключений (`ToolkitErr`, `CalcErr`, `ConvErr`).
- `history.json` — файл, в который автоматически сохраняется история вычислений калькулятора.
- `config.json` — конфигурационный файл с коэффициентами для конвертера.
- `tests/test_toolkit.py` — набор автоматизированных тестов для проверки логики.

## Калькулятор

Калькулятор использует тип `Decimal` для предотвращения ошибок точности стандарта IEEE 754 (проблем плавающей запятой).

**Поддерживаемые операции:**
- Стандартная арифметика: `+`, `-`, `*`, `/`
- Продвинутая арифметика: `//` (целочисленное деление), `%` (остаток от деления)
- Унарные операторы: `+`, `-`
- Приоритезация через круглые скобки `()`

Алгоритм не использует `eval()`. Вместо этого математическая строка проходит токенизацию, валидацию и преобразуется в обратную польскую запись (алгоритм сортировочной станции) перед вычислением.

**Пример использования:**
`python -m src.toolkit calc "(-10 // 3) + 25 % 7"`

## Конвертер

Модуль для перевода значений между различными единицами измерения. Базовые коэффициенты подгружаются из конфигурационного файла.

**Пример использования:**
`python -m src.toolkit convert 100 c k`
*(перевод 100 градусов Цельсия в Кельвины)*

## Обработка ошибок

В проекте реализована строгая изоляция ошибок. Любые нештатные ситуации (деление на ноль, несовпадение скобок, неизвестная команда, два оператора подряд) перехватываются на верхнем уровне.

- Пользователю выводится понятное сообщение об ошибке в поток `stderr`.
- Длинные системные трейсбеки (Traceback) скрыты.
- Программа завершает работу с системным кодом ошибки `2`.

## Тестирование и проверка кода

Проект покрыт 20 комплексными unit- и CLI-тестами, которые проверяют:
- Работу с экстремально большими и малыми числами (экспоненциальная запись `3E-10`).
- Точность математических операций с `Decimal`.
- Корректность отработки исключений (`pytest.raises`).
- Симуляцию терминального вызова через `subprocess.run`.

Запуск тестов:
`python -m pytest`

Проверка исходного кода на соответствие стандартам (с помощью линтера Ruff):
`python -m ruff check .`
